P.A.I.N. interaction export

interaction-events.csv: UTF-8, comma-separated, header row, timestamps in UTC.
summary.json: counts and receipt-time range from the same read-only database snapshot.
An export contains every retained interaction event; subsequent exports can overlap.
Deduplicate by id, or by tabid plus seq, when combining exports from this same installation.
Do not combine numeric ids from different installations as if they identified the same visitor.

id: database event identifier.
received_at: server receipt time, not exact client occurrence time; batches may arrive later.
userid: installation-local pseudonymous visitor id. No users-table fields are exported.
tabid: per-tab UUID; seq: event ordering and deduplication sequence within that tab.
event_type: control, country, emotion, survey, window, gesture or page.
target: fixed interface identifier, not arbitrary button text or a submitted response.
action: click/open/close/change/enable/disable/next/back/submit/start/end/visible/hidden/input.
country: selected geographic area's three-letter source key, not the visitor's location.
emotion: fixed emotional category key; enabled: toggle state; layer: active globe layer.
step: survey step number. count: interaction count where provided.
selected_count: number of selected choices, never which choices were selected.
has_text: whether a field contains text; characters: its length, never its content.
duration_ms: time open while the browser reports a visible tab; this does not prove attention.
For page/window events, sum the nonoverlapping duration segments. Their visible action also
marks a periodic 15-second checkpoint, not necessarily a new visibility transition.
Survey-step durations are cumulative within a step visit: use the final/maximum duration for
each visit, not the sum of its snapshots. A repeated step visit is a separate interval.
Choice counts are state snapshots. Count click events to measure button activations.
survey_consent: survey consent state at ingestion, not a claim of consent for other purposes.
Empty CSV fields mean not supplied; they are not zero or false.

No raw logs, IP addresses, user coordinates, survey answers, free text, user agent strings,
or media are included. Interaction histories remain pseudonymous behavioral data:
keep exports under the team's access controls rather than posting the ZIP publicly.
